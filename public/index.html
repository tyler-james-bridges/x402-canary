03 / assurance boundary

What remains unproven

Local integrity is meaningful only when its limits stay attached to every result.

false

External truth proven

HTTPS authenticates configured endpoints, not Base consensus truth. Signed effect claims do not independently prove the operator database was truthful.

false

External anti-rollback checkpoint

A local hash chain detects changes relative to retained state. Full replacement of the journal, artifacts, and receipts still requires an external WORM or signed anchor.

false

Operator database truth proven

Ed25519 proves who signed a policy-matching statement. It does not prove how the signing adapter queried its primary system of record.

required

Trusted local writer

Journal integrity depends on controlled append access and cooperating lock discipline. A stale crash sentinel requires manual, evidence-preserving recovery.

Precise claim

Core commit 3ead868 demonstrates deterministic local composition of pinned Base observations, signed effect evidence, content-addressed artifacts, and adjacent journal commits. It does not authorize an action or certify external reality.
